# Вторая версия страницы свадеб — /svadby-2 «Приглашение»

Первая версия (/svadby, тёмная, на фото и видео) ГОТОВА и не меняется. Вторая — альтернатива,
чтобы владельцы выбрали. Та же информация, другой характер: светлее, короче, как дорогая печатная
полиграфия — плотная бумага, вино, золотое тиснение, фото в один цвет.

> одинаковые карточки в двойных рамках) выглядела как шаблон с конструктора. Структура блоков и данные
> те же, подача новая — ниже.
>
> Редакция 3 (29.09.2026, этап 2). Страница была слишком короткой. Добавлены блоки «Лошади», «Зал»,
> «Как забронировать», «Как добраться»; порядок и ритм ниже. Правило: **каждая тема — один раз**
> (лошади, зал, дорога, цены — только в своём блоке).

## Идея
Сайт как свадебное приглашение от усадьбы: «Конная усадьба «Буцевичи» приглашает».
Первый экран — открытка на весь экран с сургучной печатью; дальше — страницы «буклета»:
тёмная винная вкладка с цифрами и фото, печатная программа дня.
Главный крючок тот же: невеста выезжает на регистрацию верхом, фотосессия с лошадьми — в подарок.
Длина на телефоне 390px — 14–16 экранов, блок цен (#stoimost) начинается не ниже 7-го экрана
(то есть на 7-м или раньше).

## Причины редизайна и правила против них
- **Всё центрировано и одинаково** → выравнивание в основном по левому краю; асимметричные сетки;
  нет одинаковых карточек в ряд.
- **Иллюстрации мелкие, как клипарт** → главная графика — реальные фото крупно, в дуотоне.
  Рисованные SVG — только простые орнаменты: веточка, подкова, печать, гирлянда, кольца.
- **Нет контраста масштаба** → на каждом экране один крупный элемент (заголовок 64px+, цифра или фото)
  и мелкий текст рядом: подписи мелким капсом, короткие абзацы.
- **Мутная палитра, рамки везде** → вино/слоновая кость/золото; двойная рамка с уголками — только на
  первой открытке. Разделители — тонкая золотая линия или веточка.

|---|---|---|
| ivory | #F5EFE4 | основной фон, открытки, карточки (фактура бумаги) |
| ivory-2 | #EADFCB | чередующиеся светлые секции, вторичные карточки |
| wine | #5E1F2B | главный тёмный: тёмные секции (текст ivory), заголовки, главные кнопки |
| wine-soft | #8C3A48 | надзаголовки, римские номера, «в подарок», штамп |
| gold | #B8914A | ТОЛЬКО линии, булавки, ромбы, орнаменты (на ivory 2,55:1 — не для текста) |
| gold-light | #E6CC8A | мелкий текст на wine (надзаголовки, подписи цифр) — 7,83:1 |
| ink | #231D1A | основной текст |
| ink-soft | #6A5E57 | второстепенный текст: 5,47:1 на ivory, 4,75:1 на ivory-2 |
- **Фольга** — линейный градиент #9C7433 → #E6CC8A → #9C7433, 1–2 акцента на экран.
  На светлом (`.foil-text`) блик узкий (светлый тон на ivory всего 1,37:1), тёмные тона 3,7:1 — норма
  крупного текста, плюс тонкое тиснение drop-shadow цвета вина. На тёмном (`.foil-on-dark`) — светлее.
- Шрифты (next/font, все с кириллицей): Prata — заголовки и цифры крупно; Marck Script — акценты
  в 1–2 слова («приглашает», «верхом», «территории», «в подарок»); Commissioner — текст.
- Масштаб: H1 90–120px на десктопе / 44–52px на телефоне; заголовки секций 64–96px; цифры до 150px;
  подписи — 0,64–0,72rem капсом с разрядкой.
- **Бумага**: `.tex` — статичный шум; `.emboss` — тиснение inset-тенями (светлая кромка сверху-слева,
  тёмная снизу-справа) и мягкая внешняя тень; `.paper-shadow` — тень приколотых фото.
- **Фото в стиле печати** — `DuotoneImage` (components/v2/duotone.tsx, CSS `.duotone`): бумага →
  ч/б фото multiply → краска screen (чёрное = краска, белое = бумага) → зерно. Краска — wine или ink.
  Приколотые фото (`PinnedPhoto`): поле как у отпечатка, поворот ±2–3°, латунная булавка.
- **Сургучная печать** (`WaxSeal`, SVG): неровный край, вино с бликом, подкова в рельефе.
  **Штамп «в подарок»** (`GiftStamp`): круглый оттиск, текст по кругу, повёрнут на −8°.
- Кнопки: pill; главная — wine (на тёмном — ivory), вторичная — контур. Без «магнитов».

## Ритм секций
Открытка (ivory на ivory-2 «столе») → «Всё для свадьбы» ivory → **«Лошади» wine** → «Программа дня» ivory
→ «Зал» ivory-2 → «Стоимость» ivory → **«Как это выглядит» wine** → отзывы ivory-2
→ **«Как забронировать» wine** → FAQ ivory → «Как добраться» ivory-2 → **«Ждём вас» wine** → футер ivory.
Две соседние секции одного цвета не стоят; тёмных — четыре.

## Анимации (спокойные)
- Интро (1 раз за сессию, ≤ 1,2 с, без него при reduced-motion): конверт с сургучной печатью на клапане
  раскрывается, открытка выезжает и становится первым экраном. Контент виден сразу из серверного HTML.
- Печать «ставится» на открытку с пружинкой после интро.
- Прорисовка веточек и орнаментов (pathLength); появление блоков снизу.
- Лёгкий параллакс фото при скролле — только для мыши (pointer: fine) и без reduced-motion.
- Никаких видео, кастомного курсора, прелоадера v1.
