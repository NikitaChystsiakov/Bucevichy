Верховая езда у нас может быть разной: шаговые релакс-прогулки для тех, кто впервые решил покататься на лошадях, и более активные поездки для тех, у кого уже есть опыт, и многочасовые поездки по полям для настоящих энтузиастов, и обучающие занятия для тех, кто хочет повысить свой уровень. - Часть страниц принудительно переадресует с https на http (незащищённое соединение).
- /sitemap.html — 404, хотя «Карта сайта» в главном меню.
- Одна картинка ссылается через /public_html/… (битый путь).
- Два разных Instagram-аккаунта, в фото — логотипы клиентов в разном качестве.
- Детский праздник — пустая страница без программы и фото, хотя это одна из главных услуг (судя по отзывам).
- Отзыв Вероники продублирован; некоторые отзывы обрезаны.
- Нет онлайн-бронирования/календаря — только «звоните».

**Сильные стороны для нового сайта**
- Персонажи: ослик Джонни («символ усадьбы»), козы Дуся и Пуся, ковбой Джек.
- Фишка: «всадник сам управляет лошадью, её не ведут за повод».
- История с 2002 года, 55 живых отзывов, крупные корпоративные клиенты (EPAM, Wargaming, Беларусбанк, МТС, McDonald's, Hilti…).
- Много направлений: прогулки, детские ДР/выпускные, корпоративы, свадьбы, дома с баней, пакеты для двоих, сертификаты.
