# Концепт демо-страницы /svadby — «Один день в Буцевичах»

Первая версия страницы уже есть, но её дизайн не устраивает — ДИЗАЙН ДЕЛАЕМ ЗАНОВО.
Сохраняем данные и логику: lib/wedding.ts, lib/photos.ts, lib/site.ts, расчёт цен, форму заявки
(booking-provider, lead-form, app/api/lead), SEO в page.tsx. Всё визуальное — новое:
плотное, тёмное, атмосферное, много живого медиа и взаимодействий со скроллом и мышью.

## Идея
Скролл = один свадебный день: утро → регистрация → фотосессия с лошадьми → банкет → ночь с гирляндами.
Главный крючок: невеста выезжает на регистрацию верхом, фотосессия с лошадьми — в подарок.
Каждая анимация что-то показывает (время суток, путь дня, вместимость зала), а не просто «красиво».

## Дизайн-система — новая (заменить старую bone/pine/amber в app/globals.css)
Настроение — «конный клуб в сосновом лесу»: тёмная хвоя, коньячная кожа седла, лён, латунь.
Никаких больших пустых светлых экранов: секции плотные, тёмные и светлые чередуются, каждая чётко отделена.
| Токен | Цвет | Где |

| forest | #1E2A22 | тёмные секции, ночь, футер |
| forest-deep | #141C17 | самые тёмные подложки, шторка прелоадера |
| linen | #F3ECE0 | светлые секции, текст на тёмном |

| dawn → golden → night | #F6D9B8 → #E8A15C → #16202E | градиент времени суток в «Дне свадьбы» |
- Шрифты (next/font): Cormorant Garamond — заголовки, крупно (на десктопе 80–160px), курсив для
  акцентных слов; Manrope — текст и цифры. Оба с кириллицей.
- Фактура: лёгкое плёночное зерно поверх страницы; тёплая цветокоррекция фото.
- Мотивы: пунктир «строчка седла» (разделители, рамки), подкова (прелоадер, маркеры),
  силуэт лошади одной линией, форма арки для масок фото.
- Кнопки: латунные, pill, «магнитные» на десктопе. Скругления панелей ~20px, фото — без скругления или арка.

## Анимации
- Только motion/react (уже в проекте) + CSS. GSAP/Lenis не добавлять.
- Анимировать только transform / opacity / clip-path / filter.
- prefers-reduced-motion: простое появление без скролл-эффектов.
- Тач-устройства: без кастомного курсора, наклонов и hover-эффектов (замена — тап).
- Мобильные в приоритете: владельцы откроют демо с телефона.

## Медиа
Все файлы и назначение — docs/media-svadba.md. Видео: public/video/svadba (mp4 + постер .jpg).
Видео 360–720p — только в карточках/арках/окнах, не на весь десктоп; сверху градиент и зерно.
Все <video>: muted loop playsInline autoPlay, poster, preload="none"/"metadata",
play/pause по IntersectionObserver; при reduced-motion — только постер.
